    10. THE BEST STACK IS THE SMALLEST STACK THAT PRODUCES MEASURABLE TRANSFER

    DEEP EXPLANATIONWHY STUDENTS MISS ITEASIEST CLUE
    Resource quality matters, but stack quality is ultimately demonstrated by retrieval, new-question performance, clinical execution and stable assessment trends. More tools are justified only when they add a distinct function that current tools cannot provide.Subscriptions create sunk-cost pressure, fear of missing out and the belief that completeness requires touching every respected platform.If removing a resource does not reduce measurable learning or transfer, it was probably friction.

    E. RESOURCE GOVERNANCE MASTERY GATE — BEFORE ADDING OR KEEPING A RESOURCE

    Can I name the exact gap? Is this resource uniquely suited to that gap? What output will I produce? What is the stop rule? How will I verify transfer on a fresh question/case/observed skill? Does this duplicate an existing tool?
