    Role-Readiness Proof / Capstone

    Create a production-shaped developer-experience launch kit for an AI or platform API. Map the developer journey and define time-to-first-success, integration-success and retention measures; design an OpenAPI contract and error model; ship at least one idiomatic SDK or generated client plus CLI/helper tooling; build a runnable reference application with agent/tool integration; create tutorial, how-to, explanation and reference documentation; expose a Backstage-style service entry or golden path; instrument setup failures, auth errors, latency and adoption; run clean-environment usability tests; publish a live technical demo; gather developer feedback; then convert telemetry and field evidence into a prioritized product/platform roadmap.

    Proof Rubric

    Prove the developer experience works end to end: intuitive API/SDK abstractions; idiomatic code and useful errors; runnable samples from a clean environment; secure auth and credential handling; documentation matched to user intent; self-service setup with minimal friction; measurable time-to-first-success and integration failure data; credible AI/agent interface patterns; developer-productivity evidence; and a clear feedback loop showing how developer behavior changed product, SDK, docs or platform priorities.
