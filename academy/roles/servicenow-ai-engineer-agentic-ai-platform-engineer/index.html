    Role-Readiness Proof / Capstone

    Design, build and operate a production ServiceNow agentic workflow for a real enterprise process. Use process evidence to select the use case and define measurable outcomes; build the workflow in AI Agent Studio with a clear orchestrator and scoped worker agents; implement prompts plus at least two tools using flows, scripts, Skill Kit, Integration Hub or APIs; ground decisions in governed context through AI Search, Knowledge Graph or Workflow Data Fabric; connect one external capability through MCP or A2A where justified; enforce identity, ACL/data controls, privacy/Guardian controls and human approvals; create ground-truth evals and tool-use tests; route MCP traffic through AI Gateway with governance and observability; run failure, prompt-injection and data-leakage drills; deploy with KPI monitoring and publish a runbook plus measured business impact.

    Proof Rubric

    Prove evidence-backed use-case choice; clear agent and orchestrator boundaries; precise prompts and robust tool contracts; grounded retrieval and data-context quality; correct ServiceNow ACL/permission behavior; safe external MCP/A2A connectivity; reproducible evals and ground-truth results; guardrail/privacy effectiveness; human escalation where required; diagnosable traces and gateway observability; reliable workflow recovery; measurable task completion, cycle-time or experience impact; and documented iteration based on test or production evidence.
