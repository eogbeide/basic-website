    D. 7-DAY SCHOOL-EXAM REVIEW CYCLE

    ResourceDescriptionLink
    Days 1-2Membranes + cardio. Redraw action potentials, Wiggers/PV loops and all major hemodynamic relationships from memory.
    Days 3-4Respiratory + renal. Work spirometry/VQ/clearance/acid-base problems until the direction-of-change logic is automatic.
    Day 5Endocrine + GI/reproductive integration. Build feedback-loop maps and explain perturbations aloud.
    Day 6Timed graph/equation/case block. Label each miss: concept, equation, graph, compensation, units or question interpretation.
    Day 7Targeted repair only. Repeat missed concepts using NEW graphs/cases, then finish with a mixed cumulative block.

    D. 7-DAY SCHOOL-EXAM REVIEW CYCLE — E. PHYSIOLOGY ERROR-LOG TAXONOMY

    • Direction-of-change gap - understood the concept but predicted the wrong increase/decrease.
    • Graph gap - could explain verbally but misread axes, loops, curves or shifts.
    • Equation/units gap - selected the correct relationship but used the wrong units or algebra.
    • Compensation gap - identified the primary change but missed the body's expected response.
    • Integration gap - solved one organ system but failed when two systems interacted.

    D. 7-DAY SCHOOL-EXAM REVIEW CYCLE — SCHOOL-EXAM GATE
