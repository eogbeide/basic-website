    Role-Readiness Proof / Capstone

    Transform a real manual business workflow into a production-ready AI solution. Diagnose the current process and controls; define success and acceptance criteria; query and validate source data in SQL; build an agent with tools, MCP or APIs and a grounded knowledge layer; create evals and regression tests; instrument traces, quality, latency, cost and alerts; run a failure/incident drill; pilot with real users; then deliver SOPs, training, self-service ownership and an adoption/impact readout.

    Proof Rubric

    Show a measurable workflow improvement, not an AI demo: traceable requirements; trustworthy SQL/data logic; sound agent/tool boundaries; grounded retrieval; reliable integrations; eval coverage and failure analysis; observability and recovery; security/control awareness; user feedback and adoption evidence; maintainable documentation and handoff; quantify cycle time, quality, cost, error-rate or capacity impact and explain when a simpler non-agent solution is better.
