    YEAR 1 | PAGE 20C - LEARN FROM EVERY MISS, THEN RE-TEST

    QUESTIONS ARE LEARNING TOOLS BEFORE THEY ARE SCORE TOOLS

    For each item: identify the task -> commit to an answer -> reconstruct your reasoning -> explain why the correct option is correct -> explain why the strongest distractor is wrong -> tag the error -> repair one concept -> re-test on a NEW item. Percentage correct without this review loop is weak feedback.

    E. QUESTION-REVIEW ALGORITHM — 1. Task

    What is being asked: mechanism, diagnosis, calculation, experiment, structure, adverse effect, or next step?

    E. QUESTION-REVIEW ALGORITHM — 2. Evidence

    Which stem clues actually discriminate the answer? Separate signal from incidental detail.

    3. Prediction

    Generate the expected answer/mechanism before being seduced by the options whenever possible.

    4. Distractors

    Name the feature that makes the strongest tempting alternative wrong in THIS vignette.

    5. Error tag

    Classify the miss so remediation fixes the process, not merely the fact tested in one question.

    6. Re-test

    Use a new vignette/image/graph within 24-72 hours; recognition of the old explanation is not retrieval.

    F. YEAR 1 ERROR-LOG TAXONOMY — Knowledge / retrieval

    Concept was missing, misunderstood or could not be produced without cues.

    F. YEAR 1 ERROR-LOG TAXONOMY — Reasoning / distractor

    Facts were present, but the causal chain, discriminator, localization or integration failed.

    Graph / units

    Axes, equation, units, sign or direction-of-change caused the miss.

    Image / practical

    Recognition depended on one memorized picture, angle, specimen or lab setup.

    Timing / attention

    Stem was misread, rushed, overthought or the answer was changed without new evidence.
