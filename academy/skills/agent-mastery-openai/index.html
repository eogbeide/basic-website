Mastery Ladder

FOUNDATIONS

Choose the Agent Runtime

Agents API: managed Codex harness, durable sessions and OpenAI-managed orchestration; Responses API: own the loop while using model/tool primitives; Agents SDK / Codex SDK: code-first orchestration when you operate the runtime.

INTERMEDIATE

Tools + State + Orchestration

Function tools, hosted tools, remote MCP servers, tool search and reusable skills; sessions/conversations, context management, sandboxes and artifact-producing execution; agents-as-tools, handoffs/subagents, human-in-the-loop approvals and structured outputs.

ADVANCED

Evaluate + Operate

Guardrails, sandbox boundaries, least privilege and safe consequential actions; tracing, eval suites, regression gates, latency/cost and failure diagnosis; durable sessions, recovery/rollback, production deployment and adoption evidence.

Hands-On Build Lab — Build Sequence

  • 01 – Agent choice: Create one working agent with a clearly bounded job, typed inputs/outputs and an explicit runtime choice (Agents API, Responses loop, or SDK) with rationale.
  • 02 – Ground + tools: Add grounded context and at least two tools; connect one remote MCP server or build a local/remote MCP tool integration.
  • 03 – State + artifacts: Add durable state/session behavior and one sandbox/file/code workflow where the agent produces or modifies an artifact.
  • 04 – Orchestration: Add a manager/specialist pattern using subagents, agents-as-tools or handoffs; keep authorization checks outside model judgment.
  • 05 – Guardrails: Implement input/output/tool guardrails plus human approval before one consequential write action; test prompt-injection and malformed-tool inputs.
  • 06 – Evaluate + trace: Create a representative eval set, capture traces, diagnose at least three failures, and demonstrate measurable improvement without hiding regressions.
  • 07 – Deploy: Deploy/stage the agent; document SLOs, cost/latency, rollback, incident handling, cleanup and a user/business success metric.
