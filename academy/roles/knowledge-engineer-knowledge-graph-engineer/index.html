    Role-Readiness Proof / Capstone

    Build a governed enterprise knowledge service from raw structured and unstructured sources. Define a domain ontology and taxonomy; map entities and relationships; ingest into a graph database; implement RDF/SPARQL or equivalent graph queries; add entity resolution, validation and provenance; expose semantic search and GraphRAG to an agent; then measure retrieval quality, grounding, freshness and graph quality under realistic change.

    Proof Rubric

    Prove ontology and schema quality; correct entity resolution; repeatable graph ingestion; query correctness; validation and provenance; retrieval and GraphRAG relevance; grounded agent answers with citations; security and governed access; change/version handling; observability and measurable quality. Explain when a graph is superior to relational, vector-only or document-only approaches.
