    Role-Readiness Proof / Capstone

    Design an agentic workflow for a consequential real-world task. Start with user research and journey mapping; prototype the human-agent interaction; make system status, provenance, permissions, memory and uncertainty visible; define confirmation/approval and interrupt/recovery patterns; test at least three failure modes; run usability sessions and an AI evaluation set; then iterate the design using measurable task-success, trust, error-recovery and adoption evidence.

    Proof Rubric

    Show evidence-backed user needs; clear delegation and control; calibrated trust rather than overconfidence; understandable permissions and provenance; accessible interaction design; graceful uncertainty and failure recovery; human approval at meaningful risk boundaries; high-fidelity prototype quality; usability and AI-eval evidence; measurable iteration; and design-system patterns reusable across multiple agent surfaces.
