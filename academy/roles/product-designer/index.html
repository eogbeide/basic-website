    Role-Readiness Proof / Capstone

    Take an ambiguous product problem from evidence to launch recommendation: interview users, frame the problem and north star, map IA/flows, create and test a high-fidelity prototype, use the design system and implementation constraints, define success metrics and an experiment, collaborate with engineering, and use AI-assisted prototyping where useful with human validation.

    Proof Rubric

    Show traceable customer evidence, coherent interaction/visual craft, usability findings that change the design, scalable system use, credible technical tradeoffs, metrics/experiment logic and cross-functional decision artifacts. Demonstrate high-fidelity execution, launch judgment, and clearly separate AI-generated work from designer validation.
