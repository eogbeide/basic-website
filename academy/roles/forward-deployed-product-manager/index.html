    Role-Readiness Proof / Capstone

    Own a real or simulated enterprise AI deployment from first workshop through expansion decision. Build a workflow map, baseline economics and success criteria; write an agent/product spec; map data, tool, identity and integration boundaries; document security and change constraints; create representative evals plus an A/B or staged experiment; launch with SLO, quality, latency, cost, escalation and rollback gates; run an executive steering cadence; instrument adoption and workflow impact; optimize post-launch; then write a productization memo classifying each need as platform, configuration, integration or one-off and justify any expansion only from demonstrated value.

    Proof Rubric

    Prove product judgment in the field: identify the actual workflow problem rather than transcribing requests; quantify value and success criteria; demonstrate credible AI/system fluency; resolve integration, security and change constraints; use evals and experiments to improve quality; defend production reliability, cost and rollback choices; earn senior stakeholder trust; measure adoption and workflow impact; distinguish reusable platform signal from bespoke work; and ground expansion in evidence.
