Core Hands-On Session — 10-Day Build Camp

Days 1-2: syntax + debugging kata. Days 3-4: data structures + tests. Days 5-6: REST API + SQL. Day 7: authentication/error handling. Day 8: Git + CI. Day 9: containerize and instrument. Day 10: demo, code review, retrospective. Rule: after each code-along, close the video and rebuild the same behavior from a blank repository.

Hands-On Transfer Labs

  • Same Problem, Four Languages: Implement one validated JSON API in TypeScript, Python, Java/C# and Go. Compare error handling, types, testing, dependencies, throughput and developer friction.
  • Concurrency Lab: Build producer/consumer workers; instrument queue depth, throughput and failures; compare async/event-loop vs threads/goroutines/tasks.
  • Performance Lab: Profile a CPU- or memory-heavy workload. Optimize only after measurement; document changes and regressions.
  • Mobile Mini-Ship: Build a small native feature in Kotlin or Swift with local persistence, network call, loading/error states and accessibility checks.

Pathway Proof

Choose a primary language and ship three artifacts: CLI/data utility, API/service with persistence and tests, and a user-facing or distributed application. Then re-implement one bounded module in a second language and write a tradeoff memo comparing type system, concurrency, ecosystem, performance, testability and maintainability.

Proof Rubric

  • Readable, idiomatic code
  • tests that catch real failures
  • correct data/API contracts
  • secure input and secrets handling
  • debugging evidence
  • Git discipline
  • CI
  • measurable performance where relevant
  • clear tradeoffs
  • and the ability to modify the system under a new requirement without replaying the tutorial
