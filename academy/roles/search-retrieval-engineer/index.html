    Role-Readiness Proof / Capstone

    Build a production search system for enterprise knowledge or a product catalog: data/index design, lexical baseline, embeddings/vector index, hybrid retrieval, reranker/LTR, permission-aware filters, query rewriting, an eval/judgment set with precision, recall, MRR and NDCG, latency/freshness SLOs, observability, an A/B experiment plan, failure analysis, and a retrieval-backed answer layer.

    Proof Rubric

    Separate retrieval from generation quality; establish baselines; justify index, retrieval and ranking choices; prove relevance with offline and online evidence; handle permissions, freshness and scale; quantify latency-cost-quality tradeoffs; diagnose long-tail and query failures; turn search behavior into a disciplined improvement loop.
