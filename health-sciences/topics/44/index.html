    INTERPRET BEFORE YOU CALCULATE

    Move from QUESTION -> ESTIMATE/EFFECT SIZE -> UNCERTAINTY -> VALIDITY -> APPLICABILITY. Statistical significance is not the same as clinical importance, and a p-value is not the probability that the null hypothesis is true.

    B. INFERENCE + EBM VIDEOS - CORE + ENRICHMENT — EVIDENCE INTERPRETATION CHECK

    • Distinguish Type I vs Type II error, power, confidence interval and p-value without substituting one concept for another.
    • Recognize confounding, selection, recall, measurement/observer, lead-time and length-time bias; know which design feature mitigates each.
    • Separate statistical significance from effect size, precision, clinical significance and generalizability.
