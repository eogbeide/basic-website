    THE “ONE + ONE + OFFICIAL + TARGETED” RULE

    Default stack

    • ONE primary content system for structured review when needed.
    • ONE primary question bank used deeply and longitudinally.
    • OFFICIAL blueprint + official assessments to define scope and readiness.
    • TARGETED supplements only when a specific weak domain justifies them.
