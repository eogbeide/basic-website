    Role-Readiness Proof / Capstone

    Define and launch an org-level evaluation system for an agentic product portfolio. Create the eval taxonomy and success criteria; build representative golden datasets from realistic tasks and production-like traces; instrument runs, tools and trajectories; implement deterministic, LLM-judge and human evals; calibrate judges; measure accuracy, safety, helpfulness, latency, cost and user outcomes; quantify repeatability; create scorecards and release gates; investigate failures; compare two agent/model versions; and publish governance plus roadmap recommendations.

    Proof Rubric

    Prove that the eval system supports product decisions, not leaderboard theater: valid user-centered metrics; task, outcome and trajectory coverage; representative data; calibrated judges with human reference labels; error analysis; statistical reliability; safety/transparency; reproducibility; latency/cost guardrails; production feedback loops; traceability; clear release/rollback thresholds; and roadmap decisions that follow from evidence.
