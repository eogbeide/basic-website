    Role-Readiness Proof / Capstone

    Build the security release-and-sustainment gate for a realistic connected or AI-enabled product. Produce architecture and data-flow diagrams, a threat model and secure-design decisions; integrate code review plus SAST/DAST/SCA/secret controls; generate an SBOM, provenance and signed artifacts; triage vulnerabilities by reachability and exploitability; justify cryptography, identity, network and TPM/secure-boot choices; run fuzz and adversarial tests including agent-specific abuse where relevant; define telemetry and release/rollback gates; then execute a simulated product-security incident through containment, remediation, coordinated disclosure and post-release sustainment.

    Proof Rubric

    Show exploit-to-control evidence, not checklist compliance: identify meaningful trust boundaries; move prevention into design and developer workflows; demonstrate code, dependency, provenance and artifact evidence; prioritize vulnerabilities using exploitability, reachability and customer impact; defend crypto and hardware-root choices; automate adversarial testing; isolate agent/tool permissions where relevant; and run an auditable incident-response lifecycle from detection through remediation, disclosure and lessons learned.
