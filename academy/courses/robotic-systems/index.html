    Robotic Systems

    Engineer integrated robots across mechanics, electronics, sensors/actuators, embedded and real-time software, C++/Python, ROS 2 middleware, perception, localization, SLAM, planning, control, simulation, safety, testing and hardware integration.

    BASIC
    • ▶Introduction to Robotics (Lecture 1) — MIT (~50 min)
      Start with the complete robot as an engineered system: mechanics, sensing, computation, planning and control.
    • ▶Foundations of Robot Motion — Modern Robotics (~10 min)
      Build rigorous intuition for rigid-body motion, frames, transformations and kinematics.
    • ▶ROS 2 Crash Course (~60 min)
      Learn the middleware basics - nodes, topics, services, packages and tooling used in modern robot software.
    INTERMEDIATE
    • ▶Motion Planning — Modern Robotics
      Apply configuration-space planning and collision avoidance to robot behavior.
    • ▶Robot Control — Modern Robotics
      Apply feedback, trajectory tracking and control-system thinking to physical robots.
    • ▶ROS2 Autonomous Navigation: Mapping, Planning and Execution
      Put ROS 2, SLAM, costmaps and planning together as a functioning mobile-robot stack.
    ADVANCED
    • ▶Wheeled Mobile Robots — Modern Robotics
      Architect mobile-robot kinematics, nonholonomic constraints and control.
    • ▶Camera/Radar Sensor Fusion — NVIDIA DRIVE Labs
      Integrate perception and sensor fusion into a robot/autonomy software architecture.
    • ▶NVIDIA Isaac Sim + ROS 2 in Docker
      Build reproducible simulation-to-hardware workflows using ROS 2, containers and accelerated simulation.
