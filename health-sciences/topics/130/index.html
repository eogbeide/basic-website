    ACUTE NEUROLOGY IS A SEQUENCE EXAM

    The key question is often not “what is the diagnosis?” but “what must happen next?” Stabilize when needed, identify time-sensitive mimics, localize, use the minimum decisive imaging/testing, and do not delay an intervention that is indicated by the current emergency pathway.

    C. STROKE - LAST KNOWN WELL -> GLUCOSE -> CT -> VESSEL / REPERFUSION LOGIC

    DecisionReasoning frameCommon trap
    Immediate screenABCs, exact last-known-well/time discovered, bedside glucose, focused deficit severity and anticoagulant/bleeding context.Calling it stroke without excluding hypoglycemia or missing time/medication data.
    First imagingNoncontrast head CT to distinguish hemorrhage/mass from ischemia; add vascular/perfusion imaging when it changes thrombectomy or other urgent decisions.Waiting for MRI before the initial emergency decision.
    ReperfusionEligibility depends on current guideline windows, imaging, contraindications, BP and deficit/disability. Use live stroke protocol rather than memorized outdated cutoffs.Treating all ischemic strokes the same or forgetting large-vessel occlusion evaluation.
    Hemorrhage / deteriorationReverse relevant anticoagulation, control physiology per protocol, assess neurosurgical/endovascular need and monitor for edema/herniation.Applying ischemic-stroke antithrombotic logic to hemorrhage.
    Secondary preventionMechanism matters: large artery, cardioembolic, small vessel, dissection, hypercoagulable/other.Choosing prevention before defining likely cause.

    D. SEIZURE / STATUS + HEADACHE RED-FLAG LOGIC

    SyndromeHigh-yield sequenceWhat separates answers
    Seizure / first eventStabilize -> glucose/metabolic/toxin/pregnancy context -> classify focal vs generalized + awareness -> provoked vs unprovoked -> targeted imaging/EEG as indicated.A provoked seizure is not the same management problem as recurrent unprovoked epilepsy.
    Status epilepticusAirway/oxygen/glucose -> rapid benzodiazepine -> second-line antiseizure therapy -> refractory-status escalation/continuous monitoring when needed.Do not wait for EEG or perfect etiology before treating ongoing convulsive status.
