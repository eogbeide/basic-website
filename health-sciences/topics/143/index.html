    COMMUNICATE URGENTLY

    PROCEDURAL PRINCIPLE Competence is not “I have seen this once.” For each procedure, know the indication, alternatives, contraindications, anatomy, equipment, consent/time-out, sterile technique, expected findings, complications, rescue plan and documentation - then perform only with the supervision your program allows.

    H. RADIOLOGY - QUESTION -> IMAGE -> ACTION

    • Start with the clinical question: what are you trying to confirm, exclude, stage or guide?
    • Choose/justify the modality: radiation, contrast, renal/pregnancy considerations, urgency, portability and whether ultrasound/MRI/CT/plain film changes management.
    • Read systematically: patient/date/technique/quality -> structured search pattern -> comparison -> devices/lines -> actionable finding.
    • Communicate the urgent finding: do not let a critical image sit inside a note; confirm the supervising team knows and document closed-loop communication.
