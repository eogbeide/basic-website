Bootcamp Mastery Certificate B33

Primary spine: freeCodeCamp / ExamPro AWS Cloud Practitioner 2026, deepened with Andrew Brown's 50-hour Solutions Architect Associate course and a current AWS re:Invent Well-Architected bridge. Build from regions, IAM, VPC, compute, storage and databases into serverless, observability, security, reliability and cost-aware architecture.

Benchmark: freeCodeCamp and ExamPro publish the cited AWS courses publicly, and AWS Events publishes the cited re:Invent session. Zuyini curates these free video resources and applies an independent build-and-proof completion rubric; this is not an AWS-issued certification and does not imply AWS endorsement.

Build-Along Checkpoints

  • Checkpoint 1: Create a tightly budgeted AWS sandbox and baseline governance: MFA, IAM roles, budgets/alerts, CloudTrail logging and a documented shared-responsibility model.
  • Checkpoint 2: Design a multi-AZ VPC with public/private subnets, route tables, security groups and controlled egress; prove connectivity and document trust boundaries.
  • Checkpoint 3: Deploy a resilient web workload using EC2 or containers behind a load balancer with autoscaling, S3 storage and a managed database; capture health and scaling evidence.
  • Checkpoint 4: Build a serverless/event-driven path using Lambda plus API Gateway or event sources, DynamoDB/S3 and SQS/SNS/EventBridge; show idempotency and retry/dead-letter behavior.
  • Checkpoint 5: Add least-privilege IAM, encryption/KMS where relevant, CloudWatch metrics/logs/alarms and CloudTrail audit evidence; test a denied action and explain why it fails safely.
  • Checkpoint 6: Run a Well-Architected review across reliability, security, cost, operations and performance; inject one service/instance failure and demonstrate recovery plus cost tradeoffs.

7-Day Independent Capstone

  • Day 1: Define workload, SLOs, traffic/data assumptions and cost ceiling; create the sandbox baseline with MFA, budgets, CloudTrail and least-privilege
  • Day 2: Build the network foundation: multi-AZ VPC, subnets, routes, security groups and controlled ingress/egress; publish an architecture and threat-boundary
  • Day 3: Deploy compute, object storage and a managed database; add load balancing/autoscaling and prove health checks, failover behavior and data-protection
  • Day 4: Add one serverless/event-driven workflow with Lambda and messaging/event services; prove retries, idempotency, dead-letter handling and least-authority
  • Day 5: Instrument CloudWatch dashboards/alarms and audit trails; add encryption, secret handling and one explicit security negative test with expected denial
  • Day 6: Run failure and scale experiments, perform a Well-Architected review and quantify cost/performance/reliability tradeoffs; remediate the highest-value

AWS - Build, Secure, Observe & Recover

Build an operational AWS workload rather than stopping at service definitions. Completion requires identity and network boundaries, resilient compute/data, one event-driven path, observability, security evidence, failure recovery and a documented Well-Architected review.

Proof Rubric — What Must Be Shown

  • GOVERNANCE: MFA, budgets, audit trail + shared responsibility
  • NETWORK: VPC/subnets/routes + trust boundaries
  • COMPUTE: Scaling, health checks + resilient deployment
  • DATA: Storage/database choices + protection evidence
  • SERVERLESS: Events, retries, idempotency + DLQ behavior
  • SECURITY: Least privilege, encryption + negative tests
  • OPERATIONS: Metrics/logs/alarms + recovery evidence
  • ARCHITECTURE: Well-Architected tradeoffs + cost rationale
