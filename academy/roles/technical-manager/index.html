    Role-Readiness Proof / Capstone

    Own a cross-system integration from ambiguous business need to production readiness. Write a PRD and technical requirements specification with scope, user/system flows, priorities, traceability and measurable acceptance criteria; create context, container, sequence and data-flow views; define OpenAPI/JSON schemas, OAuth/authentication, error models, versioning, idempotency, retries and rate limits; choose event, webhook, batch or real-time patterns; specify where MCP/agentic connections are appropriate; quantify availability, latency, capacity, cost, privacy and security NFRs; document design decisions and alternatives; map dependencies and critical path; define contract/integration tests, telemetry/SLOs, rollout/rollback and runbooks; then lead design review and go/no-go.

    Proof Rubric

    Trace every build item to a documented requirement and measurable acceptance criterion; separate product intent from implementation choice; make interfaces unambiguous and machine-readable; quantify NFRs; explain architecture alternatives and tradeoffs; enforce backward compatibility, security and privacy; validate schemas and contracts; prove testability with mocks, contract tests and integration tests; define telemetry, SLOs, rollout and rollback; expose dependency and risk ownership; and produce a specification an engineering team can implement without relying on unwritten assumptions.
