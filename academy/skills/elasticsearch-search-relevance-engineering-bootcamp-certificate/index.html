Bootcamp Mastery Certificate B42

Build modern search from lexical relevance to semantic and hybrid retrieval: index design, mappings, analyzers, Query DSL, BM25, ingest pipelines, dense vectors, kNN, pagination, relevance evaluation and production search UX.

Benchmark: The core Elasticsearch course is publicly available from freeCodeCamp / 3CodeCampers and the current search bridges are public videos from Elastic. Zuyini independently curates these resources and applies its own build-and-proof rubric; this is not an Elastic-issued certification or endorsement.

Build-Along Checkpoints

  • Checkpoint 1: Create an index with explicit mappings for text, keyword, numeric/date and vector fields; bulk-load a real corpus and document shard/replica choices.
  • Checkpoint 2: Build a lexical BM25 baseline with match/multi-match, bool filters, boosts and aggregations; create judged queries with expected relevant results.
  • Checkpoint 3: Add analyzer/tokenization and synonym changes; show how they alter matching and ranking, then protect changes with repeatable relevance tests.
  • Checkpoint 4: Generate/store embeddings and implement kNN or semantic retrieval; compare recall, latency and failure cases against the lexical baseline.
  • Checkpoint 5: Build hybrid retrieval with reciprocal rank fusion or equivalent; evaluate lexical vs semantic vs hybrid using MRR/nDCG/Precision@K or a justified metric.
  • Checkpoint 6: Add ingest pipeline, pagination, query profiling and operational monitoring; inject an index/node/query failure and demonstrate recovery plus rollback.

7-Day Independent Capstone

  • Day 1: Choose a search domain and corpus; define personas, query types, relevance judgments, latency target and explicit success metrics.
  • Day 2: Design mappings/analyzers and ingest the corpus; build lexical BM25 queries with filters/boosts and establish a measured baseline.
  • Day 3: Add synonyms and query/index-time analysis changes; run an offline relevance set and record wins, regressions and edge cases.
  • Day 4: Add embeddings plus vector/semantic search; tune k/num_candidates or equivalent and compare relevance, recall, latency and resource cost.
  • Day 5: Combine lexical and semantic retrieval with hybrid ranking; evaluate against the same judged set and explain where each strategy wins.
  • Day 6: Expose search behind an API/UI with pagination, profiles and telemetry; run load/failure tests and document shard/replica or scaling tradeoffs.
  • Day 7: Publish code/config, relevance judgments, metric report, latency profile, failure/recovery proof, demo and search-operations runbook.

Elasticsearch - Index, Rank, Evaluate & Operate Search

Ship a measurable search experience: design mappings and analyzers, establish a lexical baseline, add vector/semantic retrieval, combine them with hybrid ranking, evaluate relevance and prove performance plus operational recovery.

Proof Rubric — What Must Be Shown

  • SCHEMA: mappings + analyzer rationale
  • LEXICAL: BM25 baseline + judged queries
  • SEMANTIC: vectors/kNN + recall evidence
  • HYBRID: fusion + ranking comparison
  • EVALUATION: MRR/nDCG/P@K evidence
  • PERFORMANCE: latency + query profile
  • OPERATIONS: health, recovery + rollback
  • PRODUCT: usable search UX + demo
