Hands-On Build Lab — Build Sequence

  • 01 – Agent + scenario: Create a Copilot Studio agent for a real business workflow; define instructions, user groups, success measures and non-goals.
  • 02 – Ground + connect: Add approved knowledge and at least one connector/tool; separate knowledge lookups from actions.
  • 03 – MCP integration: Connect an MCP server or build one; inspect its tools/resources, disable irrelevant tools and configure authentication.
  • 04 – Workflow: Add a deterministic workflow/agent flow for one multi-step process and compare when workflow vs MCP vs connector is appropriate.
  • 05 – Identity + policy: Configure agent identity/authentication, least-privilege access and Power Platform data-policy boundaries.
  • 06 – Evaluate: Build a representative test set; inspect activity traces, tool arguments/results and failure paths; fix instructions/tool descriptions.
  • 07 – Publish + operate: Publish to an appropriate channel; configure monitoring/analytics, usage/cost awareness, change control and an incident/runbook path.

Functional System Capstone

Build a functional Copilot Studio enterprise agent that answers from governed knowledge, calls an MCP tool, invokes a deterministic workflow, performs one permissioned action, authenticates correctly, passes a test set, exposes trace evidence and is published to a usable channel with analytics and governance controls.

Proof Rubric

  • Correct orchestration among knowledge, connectors, workflows and MCP
  • clean MCP descriptions/resources
  • identity and access correctness
  • traceable tool use
  • evaluation evidence
  • safe actions
  • policy compliance
  • usable channel experience
  • monitoring and operational ownership
  • cost awareness
  • and documented deployment/change controls
