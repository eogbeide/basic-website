Hands-On Build Lab — Build Sequence

  • 01 – Agent shell: Install/configure Claude Code or Claude API/Agent SDK environment; define a real workflow, system prompt/project instructions and success criteria.
  • 02 – Knowledge + context: Add repository/files or retrieval context; establish explicit context boundaries and failure behavior.
  • 03 – Build an MCP server: Expose at least two typed tools and one useful resource; write precise descriptions, validation, auth and error handling.
  • 04 – Connect + act: Attach the MCP server; make Claude invoke tools on representative tasks; add one consequential write/action behind approval.
  • 05 – Skills + orchestration: Package one repeatable domain procedure as a Skill; optionally add sub-agents/parallel work where evidence supports it.
  • 06 – Evaluate + red team: Create representative tasks and assertions; test wrong-tool choice, injection, over-authority, secrets leakage and malformed tool responses.
  • 07 – Operate: Add logs/traces, retries/timeouts, cost/latency measures, sandbox/permission boundaries, runbook and rollback plan.

Functional System Capstone

Build a functional Claude-powered operations or knowledge-work application that reads trusted context, discovers and calls your MCP tools, performs at least one real external action with human approval, uses a reusable Skill, passes a documented eval suite, records traces, handles tool failure safely and can be demonstrated end-to-end from user request to verified outcome.

Proof Rubric

  • Working behavior
  • correct MCP tool/resource discovery
  • schema quality
  • safe authentication
  • least privilege
  • meaningful approval boundaries
  • task-success evidence
  • adversarial testing
  • useful traces
  • failure recovery
  • latency/cost awareness
  • reproducible setup
  • and a concise architecture/decision record
