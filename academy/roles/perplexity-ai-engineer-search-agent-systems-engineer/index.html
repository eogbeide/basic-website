    Role-Readiness Proof / Capstone

    Build a production search-and-agent application on Perplexity. Use Agent API with an explicit quality/cost preset or model-routing choice, real-time web search and citations; add URL or code execution plus at least one MCP or enterprise connector; persist a bounded memory/context layer and compose a reusable Skill or workflow for a long-running task. Add one governed warehouse/private-data path with identity-aware access and structured artifacts; run code only in an isolated sandbox, keep credentials outside execution, and require approval for sensitive actions. Create offline and online evals for retrieval quality, citation correctness, tool selection, task completion, latency, cost and user satisfaction; capture traces and replay failures; test prompt injection, connector failure and stale data; then ship with monitoring, rollback and a measurable product-impact readout.

    Proof Rubric

    Demonstrate grounded and cited answers; retrieval and ranking judgment; correct Agent API, preset and model choices; robust tool, MCP and connector abstractions; permission-aware enterprise context; useful Skills/workflow composition; safe sandbox and credential boundaries; resilient partial-failure and retry behavior; traceable long-running execution; production-faithful evals and replay; quantified quality, latency and cost; effective prompt-injection defenses; measurable task success/user value; and evidence that evals, traces or feedback changed the agent.
