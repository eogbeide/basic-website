Mastery Ladder

MCP

Client / Server Contract — Discover + Invoke + Exchange

Lifecycle and capability negotiation; tools, resources and prompts; transport/session behavior. Sampling and elicitation; progress/notifications; schemas, versioning and error handling. OAuth / authorization, user consent, secret handling and least-privilege tool scopes.

A2A

Multi-Agent Interop — Agent ↔ Agent

Agent cards/capability discovery, task delegation, status and artifact exchange. When to use MCP for tools/context vs A2A for peer-agent collaboration. Cross-vendor routing, protocol gateways, registries and portability boundaries.

IDENTITY

Governed Actions — Trust Boundaries

Agent workload identity, user-to-agent delegation, OAuth/IAM/Entra patterns and audit trails. Read-only vs write tools, approval steps, irreversible actions, rate limits and policy enforcement. Threat model prompt injection, confused-deputy, excessive agency and credential leakage.
