    D. WEEKLY 10-MINUTE STACK AUDIT

    Audit stepQuestionRequired decision
    1. Current gapWhat error pattern is costing the most transfer right now?Name one broad or narrow gap.
    2. Primary toolsWhich content system and Qbank own the week?One of each, unless a distinct reason exists.
    3. Official signalWhat blueprint/assessment evidence matters this week?Coverage, calibration or interface - not passive review.
    4. Targeted supplementWhat exact gap justifies it?Define output + stop rule + retest date.
    5. FrictionWhich tool creates context switching or duplicate work?Pause/drop it.
    6. TransferWhat fresh evidence shows the repair worked?New questions, delayed retrieval, observed skill or assessment trend.

    E. 10 HIGH-DISCRIMINATION ADD / KEEP / DROP DECISIONS

    #SituationDecision
    1Broad mechanism weakness across systemsKEEP/ADD structured content temporarily; reduce random volume; verify with fresh mixed questions.
    2One stable weak domain, rest strongADD one targeted supplement; KEEP primary bank; DROP idea of a full curriculum restart.
    3Three Qbanks, shallow reviewKEEP one primary bank; PAUSE the others until a distinct need appears.
    4Repeated wrong answer despite explanation reviewCHANGE repair method: reconstruct mechanism, contrast distractors, then delayed retest.
    5Bedside or OMM skill weakADD supervised practice/feedback; do not add another reading platform as the main fix.
    6Qbank high, official assessment lowKEEP core stack; audit repeats/selection/timing/domain gaps before adding broad content.
    7Official assessment stable; exam close; anxiety highDROP new-resource launches; KEEP recurring-error review, official interface, sleep and logistics.
    8Reference lookup expands into hoursKEEP as point-of-need reference; impose a time box and explicit extraction target.
    9Targeted resource used one week, no transfer gainDROP or change it; reassess whether the diagnosed gap was wrong.
    10Removing a tool changes no output or transferDROP/PAUSE it. The stack should be defined by effect, not ownership.

    TOP 10 RESOURCE-GOVERNANCE CONCEPT - 10: THE STACK IS A LIVING HYPOTHESIS

    DEEP EXPLANATIONWHY STUDENTS MISS ITEASIEST CLUE
    The One + One + Official + Targeted rule is a default operating model, not a rigid brand list. Each week, current performance evidence should confirm whether the stack is solving the present problem with the least friction.Students may treat their original study plan as a commitment even after evidence changes, or change it constantly without evidence.Keep the architecture stable; change only the layer tied to a demonstrated need.

    TOP 10 RESOURCE-GOVERNANCE CONCEPT - 10: THE STACK IS A LIVING HYPOTHESIS — F. MASTERY GATE

    [ ] I can name one primary content system, one primary Qbank, the official calibration source and every targeted supplement. [ ] Every active resource has a distinct job, measurable output and stop rule. [ ] I can explain why each paused/dropped resource is not needed now. [ ] New resources require a named gap, a time box and a scheduled transfer retest. [ ] Weekly evidence - not fear of missing out - governs the stack.
