    INTERPRET THE HORMONE PATTERN BEFORE NAMING THE DISORDER

    For each case: identify EXCESS vs DEFICIENCY -> primary gland vs central source -> expected upstream/downstream hormone pattern -> confirmatory test -> emergency risk -> mechanism-based therapy. Dynamic testing matters when a static value is ambiguous.

    B. CLINICAL ENDOCRINE VIDEOS - CORE + INTEGRATION — DISEASE-INTEGRATION CHECK

    • Pituitary: connect hormone excess/deficiency to mass effect, target-gland labs and visual-field findings.
    • Thyroid/adrenal: distinguish stable outpatient disease from thyroid storm, myxedema coma or adrenal crisis.
    • Diabetes: connect insulin deficiency/resistance to hyperglycemia, ketosis/osmotic diuresis and chronic micro/macrovascular complications.
