    RE-OBSERVATION

    FEEDBACK RULE: FEEDBACK IS NOT A PERSONAL VERDICT. IT IS PERFORMANCE INFORMATION TIED TO AN OBSERVED BEHAVIOR, A DEFINED GOAL AND A NEXT ATTEMPT. IF THERE IS NO CHANCE TO APPLY IT, THE LOOP IS INCOMPLETE.
