    Role-Readiness Proof / Capstone

    Design a production support system with trusted-knowledge RAG, case triage, tool-using agent assist, automated routing and explicit human escalation. Build evals for answer quality and resolution, instrument CSAT/deflection/SLA metrics, add access controls and observability, and create a feedback loop that converts recurring issues into product or documentation improvements.

    Proof Rubric

    Explain the service workflow and knowledge boundaries clearly; apply retrieval, routing and escalation to realistic cases; compare self-service, agent-assist and human handoff; show eval, CSAT, SLA, reliability and security evidence; quantify deflection, resolution time or customer-impact improvement.
