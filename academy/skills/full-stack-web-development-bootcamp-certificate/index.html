Bootcamp Mastery Certificate B01

Primary spine: Harvard CS50W. A project-driven progression from browser fundamentals to Django/SQL backends, interactive JavaScript interfaces, automated testing, CI/CD, scalability and security.

Benchmark: Harvard CS50W - Web Programming with Python and JavaScript -- Harvard CS50 states that learners who earn at least 70% on each CS50W project, including the final project, are eligible for a free CS50 Certificate; a verified edX option is separate. This is a Zuyini Bootcamp Mastery Certificate built around free CS50W video materials, not a Harvard-issued credential.

Build-Along Checkpoints

  • Checkpoint 1 – Frontend foundation: Responsive HTML/CSS interface, semantic structure, accessibility basics and Git history.
  • Checkpoint 2 – Backend foundation: Django routes/views/templates, forms, sessions/authentication and clean project structure.
  • Checkpoint 3 – Data layer: Relational schema, migrations, queries, relationships, validation and admin/operational workflows.
  • Checkpoint 4 – Interactive client: JavaScript DOM/events, asynchronous API calls, state/local storage and one SPA-style flow.
  • Checkpoint 5 – Engineering quality: Unit/integration/UI tests, GitHub Actions or equivalent CI, Docker/reproducible environment.
  • Checkpoint 6 – Production reasoning: Caching, load balancing, database scaling, HTTPS, XSS/CSRF/SQL-injection defenses.

5-Day Independent Capstone

  • Day 1: Define a real user problem, user stories, architecture, data model, routes/API surface and acceptance criteria.
  • Day 2: Build the authenticated Django backend and relational data model; expose at least one API endpoint.
  • Day 3: Build an interactive JavaScript/React-capable interface with asynchronous data exchange and responsive UX.
  • Day 4: Add automated tests, CI, container/reproducible setup, secure configuration and one performance/scalability improvement.
  • Day 5: Deploy or run in a production-like environment; record a demo; document architecture, failures, security decisions and next scaling step.

Functional System Capstone

Build along the CS50W video sequence, then ship an independent full-stack web application (not a clone of the instructor's project) that demonstrates a working user flow, a Django backend with authentication and at least one API endpoint, a relational data model, an interactive JavaScript/React-capable frontend, automated tests with CI, a container/reproducible environment, and deliberate security and scalability choices, deployed or run in a production-like environment with a recorded demo.

Proof Rubric — What Must Be Shown

  • FUNCTIONAL: a working app with meaningful user flow
  • BACKEND: Django routes, auth/session behavior, API
  • DATA: schema, migrations, relationships, validation
  • FRONTEND: interactive JS/UI behavior and responsive UX
  • QUALITY: tests + CI + reproducible run instructions
  • SECURITY: threats considered and controls demonstrated
  • OPERATIONS: deployment/runtime evidence and logs
  • COMMUNICATION: README, architecture diagram + demo video
