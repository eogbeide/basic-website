Hands-On Design Studio — 10-Session Product Design Bootcamp

  • 01 – Problem framing: Choose a real user workflow. Write assumptions, risks and research questions; avoid jumping to screens.
  • 02 – Interviews: Run 5 discovery interviews when appropriate; use open questions and record evidence, not conclusions.
  • 03 – Synthesis: Affinity map, jobs/tasks, journey and prioritized pain points. Separate quotes/observations from interpretations.
  • 04 – IA + flows: Create sitemap/navigation and task flows; test labels and states before high-fidelity polish.
  • 05 – Wireframe: Sketch multiple alternatives; critique against user task, constraints and error cases.
  • 06 – UI craft: Apply type, color, spacing, hierarchy, responsive layout and accessible contrast.
  • 07 – Components: Build reusable components/variants, auto-layout and starter design tokens.
  • 08 – Prototype: Create interactive happy path plus empty, loading, error, permission and recovery states.
  • 09 – Usability: Test representative tasks; note breakdowns, severity and evidence. Iterate the design.
  • 10 – Portfolio: Publish problem → evidence → decisions → prototype → testing → changes → outcome/next experiment.

Portfolio Proof Rubric

Problem backed by user evidence; research ethics/consent; coherent IA and task flows; accessible visual craft; component consistency; realistic states; interactive prototype; usability evidence; iteration from observed failures; documented tradeoffs; outcome metric or test plan; and a concise case study that shows judgment rather than decorative screens.
