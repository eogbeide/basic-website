Build-Along Checkpoints

  • Checkpoint 1: Containerize a reproducible local stack with Postgres and define cloud/IaC choices for the target environment.
  • Checkpoint 2: Ingest a real API/file source with dlt or equivalent; support schema evolution and an incremental load.
  • Checkpoint 3: Orchestrate scheduled pipelines with Kestra or equivalent; demonstrate retries, backfills and parameterized runs.
  • Checkpoint 4: Model data in BigQuery/warehouse layers and build dbt staging, intermediate and mart models with tests and docs.
  • Checkpoint 5: Process a larger partitioned dataset with Spark and justify partitioning, joins, persistence and cost/performance choices.
  • Checkpoint 6: Build a Kafka/Flink streaming path, capture late/out-of-order behavior and prove one checkpoint/recovery scenario.

7-Day Independent Capstone

  • Day 1: Choose a real data domain; define consumers, source contracts, freshness SLOs, privacy constraints and architecture.
  • Day 2: Build ingestion and raw/bronze storage; add incremental loading, schema handling and reproducible local/cloud setup.
  • Day 3: Add orchestration with schedules, backfills, retries and one intentionally failed run that you recover cleanly.
  • Day 4: Build warehouse/lakehouse models plus dbt tests, documentation and a decision-ready dashboard or downstream dataset.
  • Day 5: Add a Spark batch job and measure at least one performance or cost tradeoff with realistic data volume.
  • Day 6: Add a streaming path; test delivery semantics, late events or restart recovery and record operational evidence.
  • Day 7: Publish repo, lineage/architecture, data-quality results, SLO evidence, runbook, demo video and lessons learned.

Data Engineering - Build, Operate & Prove

Build an end-to-end data platform that ingests, orchestrates, transforms, serves and monitors real data. Completion requires batch and streaming evidence, quality controls, reproducibility and production-style operations.
