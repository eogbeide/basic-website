Integrative Capstone

Day 1 - Define 2-3 measurands (for example temperature, pressure/force, flow or motion), range, accuracy, bandwidth and environmental constraints. Day 2 - Select sensors/transducers; design bridge/op-amp/filter conditioning, grounding/shielding and protection. Create the wiring/I/O diagram. Day 3 - Build the DAQ chain: sampling rate, anti-aliasing, ADC resolution, synchronization, metadata and storage. Capture raw and conditioned signals. Day 4 - Calibrate against a reference; estimate uncertainty, noise, drift and dynamic response. Add threshold/alarm logic or a PLC/control interface. Day 5 - Run a fault/noise test, document recovery, and publish plots, calibration curve, uncertainty budget, raw data, acceptance criteria and test report.

Evidence Standard

  • Show the actual measurement chain: sensor selection rationale
  • conditioning schematic
  • grounding/shielding choices
  • DAQ settings
  • calibration evidence
  • uncertainty/noise analysis
  • dynamic response
  • alarm/control logic
  • raw data
  • reproducible plots
  • one injected fault
  • traceable pass/fail criteria and lessons learned
