    D. 7-DAY SCHOOL-EXAM REVIEW CYCLE

    ResourceDescriptionLink
    Days 1-2Innate + complement + antigen presentation. Rebuild pathway maps and cellular roles without notes.
    Days 3-4T/B cells, antibodies, tolerance and hypersensitivity. Use mechanism tables, then mixed vignette questions.
    Day 5Immunodeficiencies: work from infection/organism/lab pattern to the missing immune function, not from disease name to facts.
    Day 6Autoimmunity + transplant + immunomodulator targets. Complete a timed mixed school-style block.
    Day 7Re-test every miss on NEW vignettes; watch one targeted enrichment video only if the mechanism remains unclear.

    D. 7-DAY SCHOOL-EXAM REVIEW CYCLE — E. IMMUNOLOGY ERROR-LOG TAXONOMY

    • Cell/mediator gap - confused which cell, cytokine, antibody or complement component performs the function.
    • Sequence gap - knew components but not activation order or upstream/downstream consequence.
    • Pattern gap - recognized an immunodeficiency name but not the organism/lab pattern that reveals it.
    • Hypersensitivity gap - confused antibody-bound cell injury, immune complexes and T-cell-mediated injury.
    • Transplant/therapy gap - misidentified rejection timing/mechanism or biologic-drug target and downstream risk.

    D. 7-DAY SCHOOL-EXAM REVIEW CYCLE — SCHOOL-EXAM GATE
