    K. CDM CASE LOGIC

    • Cases contain 2-4 questions focused on data acquisition, interpretation/diagnosis, treatment, counseling and follow-up.
    • Response types include extended multiple choice and short answer. Some extended-MCQ prompts may require more than one correct option; obey response limits.
    • Progression is consequential. Once an earlier case part is submitted, you cannot return and change it. Commit only after checking the task and response limit.
    • Osteopathic framing stays active. OPP/OMM, osteopathic patient care, communication, professionalism and systems-based practice remain part of the Level 3 blueprint.
