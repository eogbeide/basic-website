    Role-Readiness Proof / Capstone

    Own a production service end to end: design a cloud-native API/microservice with authentication and SQL/NoSQL persistence; document interfaces and ADRs; implement unit/integration tests, secure coding checks, CI/CD and code review; deploy with telemetry, SLOs and cost/performance targets; run a failure/incident drill and postmortem; then use an AI coding assistant for one meaningful change and document the tests, security checks and human review used to verify it.

    Proof Rubric

    Defend architecture and tradeoffs; show maintainable code, Git/review discipline and automated tests; demonstrate authentication/data protection and CI/CD; quantify latency, reliability and cost; diagnose a production failure from telemetry; resolve an incident; and show responsible AI-assisted coding with human verification and clear evidence of what the tooling did versus what the engineer validated.
