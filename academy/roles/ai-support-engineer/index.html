    Role-Readiness Proof / Capstone

    Own a mission-critical enterprise AI/API escalation from first report through prevention. Reproduce an auth/integration or model-behavior fault in a test harness; capture request IDs, logs, metrics and traces; map service and customer architecture; isolate retries, rate limits, permissions, data/tool or agent boundaries; run targeted evals for AI-specific failures; coordinate incident roles, status updates and a safe workaround/rollback; automate one repetitive investigation step; publish a runbook/knowledge article; complete a blameless postmortem with measurable actions; then submit a product/docs feedback package with issue frequency, customer impact and evidence.

    Proof Rubric

    Prove evidence-led ownership: a reproducible failure case; correct API/auth/network reasoning; useful telemetry and trace interpretation; distributed-system diagnosis; crisp enterprise communication and escalation; explicit AI/agent evals where relevant; safe automation with human checks; durable runbook/postmortem actions; and a closed feedback loop that reduces recurrence or time-to-resolution.
