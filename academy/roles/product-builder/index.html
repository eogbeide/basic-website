    Role-Readiness Proof / Capstone

    Take one real customer problem from evidence to a bounded production launch. Conduct user interviews, write the problem/value hypothesis and success metrics, prototype and usability-test the experience, then build a responsive full-stack product with React/Next.js + TypeScript, backend APIs and persistent data. Add one useful AI agent/tool workflow, instrument product and AI-quality metrics, create an eval/regression set, define permissions/privacy controls, deploy with observability and SLOs, use a staged rollout with fallback/rollback, run one experiment, and use adoption/retention evidence to drive the next iteration.

    Proof Rubric

    Show customer evidence rather than invented requirements; defend scope, UX and architecture tradeoffs; ship working frontend/backend/API/data flows; demonstrate reliable AI/tool integration with evals; measure usability, latency, quality, cost and retained usage; test safely before broad rollout; diagnose one production failure from telemetry; and show that feedback, experiments and real usage changed the product rather than merely validating the original idea.
